# nextpost

AIチャットサービスのメッセージを**指定した時刻に自動送信**するJavaScriptブックマークレットです。

## 対応サービス

- **Claude** (claude.ai)
- **Gemini** (gemini.google.com)
- **ChatGPT** (chatgpt.com)
- その他、`contenteditable` または `textarea` による入力欄を持つAIチャットサービス

---

## 仕様

| 項目 | 内容 |
|------|------|
| 実行方式 | ブックマークレット（JavaScriptをブックマークとして登録） |
| 送信方法 | 送信ボタンのクリック → 失敗時はEnterキーイベントで代替 |
| 表示UI | 画面右上にカウントダウンバッジを表示 |
| キャンセル | バッジ上の「キャンセル」ボタンで予約を取り消し可能 |
| 翌日送信 | 指定時刻が現在時刻より過去の場合、翌日の同時刻に送信 |
| 依存関係 | なし（外部ライブラリ不要） |

### 動作フロー

```
ブックマークレット実行
  └─ 送信時刻を入力（プロンプトダイアログ）
       └─ 画面右上にカウントダウンバッジ表示
            ├─ キャンセルボタン押下 → 予約キャンセル
            └─ 指定時刻到達
                 ├─ 送信ボタン検出 → クリックで送信
                 └─ 送信ボタン未検出 → 入力欄にEnterキーで送信試行
```

---

## ブックマークへの登録方法

### 方法A：ソースをそのまま貼り付ける

1. ブラウザのブックマークバーを右クリックし「ページを追加」または「ブックマークを追加」を選択
2. 名前に `nextpost`（任意）を入力
3. URLの欄に [`nextpost.js`](./nextpost.js) の内容をそのまま貼り付ける
4. 保存する

> **注意:** URLフィールドの先頭が `javascript:` から始まっていることを確認してください。

### 方法B：ドラッグ＆ドロップ（GitHub Pages 利用時）

GitHub Pages などでページを公開している場合、ページ上のリンクをブックマークバーへドラッグするだけで登録できます。

---

## 使い方

1. **AIチャットサービスを開き、送信したいメッセージを入力欄に入力しておく**（まだ送信しない）
2. **ブックマークバーの `nextpost` をクリック**
3. ダイアログが表示されるので、**送信したい時刻を入力**する
   - 例: `18:00` または `18:00:00`
4. OKをクリックすると、**画面右上にカウントダウンバッジ**が表示される
5. 指定した時刻になると**自動的にメッセージが送信**される

### キャンセルする場合

カウントダウン中に右上バッジの **「キャンセル」ボタン** を押すと予約が取り消されます。

---

## 注意事項

- ブックマークレットはページを閉じたり、リロードすると**キャンセルされます**
- ブラウザのタブをアクティブに保ち、スリープしないようにしてください
- サービスのUIアップデートにより送信ボタンの検出が失敗する場合があります
